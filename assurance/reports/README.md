The [testing chapter](../../docs/testing.md) describes the harnesses.

| [Platform assumptions](platform-assumptions.md) | Generated register and board criteria |

| [Constant-time findings](constant-time-findings.md) | Audit findings and their fixes |
| [Authorization slice results](authorization-slice-results.md) | Measurements from the refinement design |
